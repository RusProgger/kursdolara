# 💱 kursdolara

---

## 🇷🇺 Русский

### 📌 Описание
`kursdolara` — простая консольная программа для отображения курса доллара.

Курс может вводиться вручную или быть задан в коде.

Проект создан в учебных целях для практики базового программирования.

### 🚀 Возможности
- Вывод курса доллара в консоль  
- Ввод значения пользователем  
- Минимальная логика без библиотек  

### 🧠 Цель проекта
Практика:
- переменных  
- ввода/вывода  
- базовой логики программы
